# Lối gọi cũ trong Codex

Tên skill này được giữ để các câu lệnh cũ của nhóm còn dùng được. Với công việc nhiều màn hoặc nhiều vai trò, đọc và thực hiện `ui-ux-director/SKILL.md`. Với một phần việc nhỏ, chọn đúng skill `ui-role-flow`, `ui-mock-contract`, `ui-vietnamese-content`, `ui-visual-direction`, `ui-interaction-build`, `ui-accessibility-check` hoặc `ui-browser-proof`.

Không dùng lại quy trình thị giác cũ như một hệ thứ hai. Giữ yêu cầu hiện tại của người dùng và bằng chứng từ dự án làm nguồn quyết định.
